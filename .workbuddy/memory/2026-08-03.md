# 2026-08-03 工作记录

## 鲲鹏 C2000 Max ImmortalWrt 云编译项目搭建

### 背景
- 用户想为鲲鹏 C2000 Max (MT7987) 开发 OpenWrt 固件
- 功能需求：科学上网(OpenClash)、广告过滤(AdGuard Home)、NAS 文件共享
- 本地无 Docker，采用 GitHub Actions 云编译方案

### 技术选型
- 源码：padavanonly/immortalwrt-mt798x-6.6 的 mt798x-mt799x-6.6-mtwifi 分支
- 内核：6.6 + 闭源 MT799x WiFi 驱动
- 基础配置：defconfig/mt7987_mt7992.config

### 创建的文件
- `.github/workflows/build.yml` — GitHub Actions 云编译工作流
- `feeds.conf.default` — 第三方软件源配置
- `diy-part1.sh` — 编译前插件源添加脚本
- `diy-part2.sh` — 编译后默认配置修改脚本
- `configs/c2000max-packages.seed` — 软件包种子配置
- `README.md` — 完整使用说明（fork → 编译 → 刷机）
- `.gitignore`
